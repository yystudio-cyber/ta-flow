# 飞书需求 → 职位 一键复制（浏览器插件）

装一次，以后每次开飞书招聘就自动生效，不用再开 TA 平台。

## 装（3 步，约 1 分钟）

1. 把 `feishu-req2job` 这个**文件夹**放到一个不会被删的位置，例如 `D:\ta-plugins\feishu-req2job`
   （如果拿到的是 zip，先解压出来；**不要**放在下载/临时目录，删了插件就失效）。
2. Chrome 地址栏输入 `chrome://extensions` → 右上角打开 **开发者模式**。
3. 点 **加载已解压的扩展程序** → 选中第 1 步那个文件夹 → 完成。

装好后打开**飞书招聘**（从工作台点进去即可），进到需求相关页面时右下角会出现面板。

> ⚠️ **装好/更新后，已经开着的飞书页面要刷新一次（F5）**，插件才会在那些页里生效。
> 点浏览器右上角的插件图标也能看到这条提醒和使用步骤。

> 公司电脑的 Chrome 若被 IT 策略禁用了「开发者模式/加载已解压扩展」，这条路走不通，
> 需要 IT 把插件加进白名单。

## 用

1. 打开一条**审批通过**的需求详情。
2. 点面板上的 **⚡ 一键：需求 → 新建职位**。
3. 插件会：查审批状态 → 提取需求 → 自动点开「新建职位」→ 按三步向导依次填 →
   **停在「保存并完成更多设置」之前**。
4. 在「**已粘贴**」里核对字段，逐项对完，**自己点提交**。

### 面板上的键

**需求页**

| 键 | 干什么 |
|---|---|
| ⚡ 一键：需求 → 新建职位 | 主路径。一路填到最后一步停下 |
| 📋 复制当前需求 | 把**整页**能认出来的字段都抓进「已粘贴」（一键内部也会做这一步） |
| 🎯 逐项点选 | 抓漏了字段时用：鼠标对准**某一个字段**，高亮的就是会取走的那一条，点一下加进去。可以连着点多个，按 **Esc** 结束 |

**向导页**

| 键 | 干什么 |
|---|---|
| 🚀 填充新建职位 | 已经手动开着向导时用它（会自动走完三步） |
| 🔍 扫描表单字段 | 「某个字段没填上」时，看工具在当前页读到了哪些字段，用来定位问题 |
| ↺ 重置填充记录 | 清掉「我上次填了什么」的记忆（只影响「智能覆盖」模式的判断） |

### 「已粘贴」就是要填进去的内容

面板中间那个框里是什么，就会往职位表单里填什么。**可以直接改，改完立刻生效，不用点保存**。
填之前扫一眼这里，比填完了再去表单上一个个核对省事。

**填充方式**默认「仅填空字段」——只填空的，页面上已经有的值一律不动。

## 它不会做什么

- **不会替你提交**。走完第 3 步就停下，提交永远是人点。
- **不会碰没通过审批的需求**。只放行「审批通过」；读不到审批状态时默认拒绝
  （要放行得在面板上再确认一次）。
- **不发任何网络请求**。只操作页面上已经渲染出来的内容。
- **不申请任何 Chrome 权限**（`manifest.json` 里没有 `permissions`，也没有 `host_permissions`）。

## 几个已知的坑

- **填充期间别切走标签页**。Chrome 会把后台标签页的定时器降到约 1 次/分钟，
  填充会慢到像卡死。面板上也有这句提醒。
- **职位名称是从页面标题推断的**。飞书需求详情里没有「需求名称」这一行，
  只能取页面标题。报告里会黄字提醒，**提交前务必核对职位名称**。
- **校招需求要改「招聘流程」**。目前固定填「默认社招流程」，校招场景得手动改。

## 出问题怎么给信息

面板里点 **🔍 扫描表单字段**，把结果连同报告一起截图发出来。
要更详细的日志，在飞书页面的控制台执行 `localStorage.setItem('ta-req2job:debug','1')` 后刷新，
过程明细会打到 Console。

## 给维护者

- 插件代码 **不是手写的**：`content.bundle.js` 由 `npm run feishu-ext:build` 从
  `src/content.js`（唯一真源）生成。
  **不要直接改 bundle**，改源再重建。`npm test` 里的 `feishu-ext:check` 会守住这条。
- 打包给 TA：`npm run feishu-ext:build -- --zip` → 产物在 `dist-ext/`。
- 两条测试线：`npm run feishu:lab`（平台沙箱路径）、`npm run feishu-ext:e2e`（插件路径）。
