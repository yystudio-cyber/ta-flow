## 社交平台首条 Issue（可选，但强烈建议）

建一个置顶 Issue，标题用 `👋 欢迎！说说你的招聘场景`，
让第一个来的人有地方说话。正文可以复制下面这段：

```markdown
这个仓库是从真实招聘工作里长出来的工具，但它现在只服务于一种工作场景。

想让更多人用得上，我需要知道**你的**场景长什么样：

- 你在招什么岗位？（技术 / 财务 / 销售 / 运营…）
- 现在最耗时间的一步是哪一步？
- 你有没有一套自己判断"这个人行不行"的标准？能说清吗？

说清这些，我才知道该往哪儿改。直接在本 Issue 回复就行，不用照着模板。
```
